# NetLift: A Causal Decision System for Incremental Profit Optimization

DEPI graduation project, Microsoft Machine Learning Engineer Track. Team NHA-5-174.

NetLift estimates, for each customer, how much a marketing contact changes that customer's
behaviour (uplift, or the conditional average treatment effect), and uses the estimate to spend a
fixed campaign budget on the customers the contact actually persuades. It is built on two public
randomized marketing experiments, Criteo-UPLIFT and Hillstrom MineThatData, and is evaluated with
Qini, AUUC and uplift@k with bootstrap confidence intervals, against a response-model baseline.
